# Student Performance Analysis
 
 ## About the Project
This project analyses student performance using Python and Pandas. It explores students' marks, attendance, and academic performance to identify useful insights.

## Objectives
- Analyse student marks across different subjects.
- Calculate total and average marks.
- Compare student performance.
- Explore the relationship between attendance and academic results.

## Technologies Used
- Python
- Pandas
- NumPy

## Dataset
The dataset contains student information, including:
- Name
- Branch
- Age
- Attendance
- Python marks
- DBMS marks
- Mathematics marks

## Key Analysis
- Identify students with the highest marks.
- Calculate total and average scores.
- Compare performance across branches.
- Explore attendance and marks.
