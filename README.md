# Student Performance Analysis

## About the Project
This project uses Python and Pandas to analyse student performance and understand academic results.

## Objectives
- Calculate students' total and average marks.
- Identify students with the highest scores.
- Compare student performance across subjects.
- Explore attendance and academic results.

## Technologies Used
- Python
- Pandas
- NumPy

## Dataset
The dataset includes student names, branches, ages, attendance, and marks in Python, DBMS, and Mathematics.

## What I Learned
- Working with Pandas DataFrames.
- Selecting rows and columns.
- Calculating totals and averages.
- Analysing data using Python.

## Future Improvements
- Add charts and visualisations.
- Build a student performance dashboard.
- Explore relationships between attendance and marks.
